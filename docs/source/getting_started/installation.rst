Installation
============

Install the package from `pypi`_ with

.. _pypi: https://pypi.org/project/nuclearmasses/

.. code-block:: bash

   pip install nuclearmasses

Contributions are always welcome so you can also clone the module to create a pull/merge request

.. code-block:: bash

   git clone https://github.com/php1ic/nuclearmasses

If you are interested in raising a `PR`_ please read the `contributing`_ file for instructions on what to install and the checks to run prior to submission.

.. _PR: https://github.com/php1ic/nuclearmasses/pulls
.. _contributing: https://github.com/php1ic/nuclearmasses/blob/main/CONTRIBUTING.md
